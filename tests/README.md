# Azure MCP Server Tests

This directory contains tests and testing tools for the Azure MCP Server.

## Automated Tests

The automated tests are implemented in this folder and can be run via the standard .NET testing framework.

## Code Coverage

Code coverage results are tracked to ensure quality of the test suite.

## Manual Testing Tools

In the `Manual` folder, you'll find tools and utilities for manual testing of the Azure MCP Server:

- `sse-test.html`: A browser-based tool to test SSE connections

For more information, see the [Manual Testing README](Manual/README.md).
